# Piscines Montréal — PWA V2

Version 2 de l'application GitHub Pages.

## Modifications V2
- Heure saisissable manuellement + liste par pas de 15 minutes.
- Point de départ : géolocalisation ou adresse saisie.
- Recommandation bleue sur la carte et dans la liste.
- Liste paginée par 10 piscines, classées par distance lorsque le point de départ est défini.
- Répertoire élargi aux piscines publiques gratuites recensées à partir du répertoire Ville de Montréal; piscines extérieures hors saison conservées.

## Mise en ligne
Remplacer les fichiers du dépôt GitHub par ceux de ce dossier, puis faire un commit. GitHub Pages republie automatiquement.

## Remarque
Les horaires changent selon les sessions, jours fériés et événements. Les liens « Source » renvoient aux fiches officielles. Certaines installations gratuites peuvent demander une carte ou une preuve de résidence.
